Privacy Policy

Last updated: 18 October 2026

FootyFrenzy Autopilot ("the app") is a private tool operated by the owner of the YouTube channel FootyFrenzy. It is used only for that channel and has no other users.

What the app accesses

After the channel owner signs in with Google and grants permission, the app uses YouTube API Services to:

  • upload and schedule videos on the owner's channel;
  • post comments as the channel under the channel's own videos;
  • read statistics (views, watch time, comments count) of the channel's own videos via the YouTube Analytics API.

The app does not access, collect or store data of other YouTube users or viewers.

How data is stored

The Google sign-in token is stored only on the owner's own computer and as an encrypted secret in the owner's private code repository, so the app can run on a schedule. Video IDs and statistics of the channel's own videos are stored in that private repository. No data is sold, shared with third parties or used for advertising.

YouTube and Google

The app uses YouTube API Services. By using it you also agree to the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

TikTok, Instagram and Facebook

After the owner signs in with TikTok or Meta and grants permission, the app uses the TikTok Content Posting API and the Meta Graph API only to publish the channel's own videos (with title and hashtags) to the owner's own TikTok account, Instagram account and Facebook Page, and to read the basic profile info needed for that. Tokens are stored in the same way as described above. No data of other users is accessed. See the TikTok Privacy Policy and the Meta Privacy Policy.

Revoking access

Access can be revoked at any time via Google account permissions or security settings. Stored tokens are then useless and are deleted by the owner. TikTok access can be removed in the TikTok app (Settings and privacy → Security → Apps and services), Meta access in Facebook settings (Apps and websites).
