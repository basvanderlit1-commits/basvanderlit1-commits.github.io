FootyFrenzy Autopilot

FootyFrenzy Autopilot is a private tool used only by the owner of the YouTube channel FootyFrenzy. It creates data-driven football Shorts (statistics, own graphics, no match footage) and uploads them to that one channel.

With the channel owner's permission it uses the YouTube Data API and the YouTube Analytics API to:

  • upload and schedule videos on the FootyFrenzy channel;
  • post the channel's own comment under those videos;
  • read view and watch-time statistics of the channel's own videos.

The tool has no other users and is not offered to the public.
